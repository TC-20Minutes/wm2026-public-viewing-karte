# CLAUDE.md — project orientation for agents

Read this first. It explains what this project is, how it's wired, and the
non-obvious decisions/gotchas so you don't relearn them the hard way. For
setup/hosting/rebuild commands aimed at humans, see `README.md`.

## What this is

A **static, mobile-first, iframe-embeddable map** of the **112 public-viewing
venues** across Switzerland for the **2026 Football World Cup**, built for
**20 Minuten**. No backend — it's plain HTML/CSS/JS + Leaflet, hosted on GitHub
Pages and embedded in 20 Minuten articles via `<iframe>`.

- **Live site:** https://tc-20minutes.github.io/wm2026-public-viewing-karte/
- **Repo:** https://github.com/TC-20Minutes/wm2026-public-viewing-karte (public, branch `main`, Pages from `/` root)
- **Source data:** `data/Public_Viewing_…xlsx` (sheet `Public Viewing`).

## Architecture (what each file does)

```
index.html                 # the page (iframe target): toolbar + #map + #list + detail sheet
css/style.css              # all styling; brand tokens at :root; Matter @font-face
js/app.js                  # ALL behaviour (vanilla JS, IIFE): map, clustering, filter,
                           #   geolocate, list/map toggle, detail sheet, mask, canton highlight
js/data.json               # GENERATED by build/build_data.py — the 112 venues
assets/teasers/*.webp      # GENERATED — self-hosted Open Graph preview images (80/112)
assets/teasers/placeholder.svg   # branded fallback when a venue has no usable og:image
assets/geo/outline.geojson # GENERATED — Switzerland + Liechtenstein (mask + border)
assets/geo/cantons.geojson # GENERATED — cantons + Liechtenstein, tagged with `key`
assets/fonts/Matter-*.woff2# web fonts (converted from cd_ci/ .otf)
assets/markers/            # (pin is inline SVG in app.js; folder reserved)
vendor/                    # pinned local copies of Leaflet + markercluster + gesture-handling
build/build_data.py        # xlsx -> data.json + fetch/optimise teaser images
build/build_geo.py         # geoBoundaries -> outline.geojson + cantons.geojson
data/…xlsx                 # source spreadsheet
.nojekyll                  # so GitHub Pages serves vendor/ and dotfiles untouched
cd_ci/                     # brand guidelines + Matter .otf — GIT-IGNORED (internal, large)
```

Everything the site needs is **self-hosted/vendored** — no runtime CDN
dependency except the map tiles (CARTO/OSM).

## How data flows

1. `build/build_data.py` reads the xlsx, extracts each venue's real URL from the
   Excel `HYPERLINK()` formula, fetches its `og:image`, downscales to WebP in
   `assets/teasers/<id>.webp`, and writes `js/data.json`
   (`{id,name,address,canton,lat,lon,description,url,image}`). Prints a
   fetched-vs-failed summary. ~32 venues have no usable preview (Instagram needs
   login, some sites block/serve logos) → `image:null` → branded placeholder.
   **This is expected**, not a bug.
2. `build/build_geo.py` downloads boundaries from geoBoundaries (cached in
   `build/geo_cache/`, git-ignored), maps canton `shapeName` → the canton label
   used in the data, rounds coords, and writes the two `assets/geo/*.geojson`.
3. `js/app.js` fetches `data.json` + the two geojson at runtime and renders.

`LOT-Koordinaten` in the xlsx is **longitude** (despite the name). The data's
`canton` field groups **Appenzell (AI/AR)** as one label and includes
**Liechtenstein** as a "canton" — `build_geo.py`'s mapping handles both.

## Key decisions & gotchas (don't re-break these)

- **Base map:** monochrome **CARTO Positron `light_nolabels`** (OSM-based, no
  place names), fallback to standard OSM on repeated tile errors. We previously
  used swisstopo — intentionally replaced.
- **Only CH + FL visible:** an **inverse mask** (world rectangle with CH+FL
  punched out as holes, even-odd fill) hides neighbouring countries. Canton
  borders are drawn from `cantons.geojson`; the selected canton is highlighted
  and zoomed to on filter change.
- **Leaflet pane stacking (important!):** `#map` is given `z-index:1` in CSS to
  make it its own stacking context. Without this, Leaflet's internal panes
  (z 200–700) paint **over** the `#list` overlay and break the list/map toggle.
  Custom panes: `maskPane`(350) < `cantonBorderPane`(355) < `cantonPane`(360,
  highlight) < `outlinePane`(370) < markers(600). All non-marker panes have
  `pointer-events:none`.
- **List vs map view:** mutually exclusive via `#app[data-view]` + explicit
  `display` rules — NOT the `hidden` attribute (a CSS `display` rule overrides
  `hidden`, which caused an early bug).
- **Default fit / mobile:** map uses `zoomSnap:0` so `fitBounds(outlineBounds,
  {padding:[22,22]})` fits the whole country tightly without integer-zoom
  clipping. `fitCountry()` re-runs after layout settles (timeouts) and on
  resize/orientation until the user interacts (`userInteracted` flag, guarded by
  `programmaticMove`). Don't replace this with a one-shot fit — mobile toolbars
  change the map height after first paint and re-clip it.
- **Mobile UX:** detail = bottom sheet (swipe/scrim/Esc to close); desktop =
  floating card. Touch targets ≥44px. **Gesture handling**: one finger scrolls
  the article, two fingers pan/zoom (so the iframe doesn't trap page scroll).
- **No search box:** removed on purpose — the canton filter covers it.
- **Reset button** ("Zurücksetzen"): clears the filter, closes the sheet, returns to map view, and re-fits the
  whole country (`els.reset` handler in app.js).
- **Theming / dark mode:** an inline `<head>` script sets `<html data-theme="light|dark">` from `?theme=` (embeds
  can force it to match the host) or `prefers-color-scheme`. CSS keys off `:root[data-theme="dark"]` with semantic
  tokens (`--bg`,`--surface`,`--surface-2`,`--text`,`--text-muted`,`--icon`,`--line`,`--widget-border`,`--scrim`,
  `--map-bg`). Dark `--bg` is the 20 Minuten `#1D242A`. JS reads `data-theme` into a `THEME` object that picks the
  CARTO tiles (`light_nolabels`/`dark_nolabels`) and the mask/border/outline/highlight colours. **Don't hardcode
  colours in JS map layers** — use `THEME`. Keep on-accent text white in both themes (`--on-accent`).
  The theme can also change at **runtime via `postMessage`** so an embed follows the host article live:
  `applyTheme(theme)` rebuilds `THEME`, swaps the tile URL (`basemap.setUrl`) and re-`setStyle`s the mask/outline/
  border/highlight layers (kept in outer vars `maskLayer`/`outlineLayer`/`cantonBorderLayer`/`highlightLayer`).
  Accepted message: `{type:"set-theme", theme:"dark"|"light"}` (or a bare `"dark"`/`"light"` string).
- **Widget border:** `#app` has a 1px `--widget-border` + 12px radius + `overflow:hidden` so the embed reads as a
  widget in both themes. (Fixed `.sheet`/`.scrim` are intentionally not clipped by it.)
- **iframe scroll-jump (important):** clicking a venue must NOT make the host page scroll. Three guards: the map is
  created with `keyboard:false` (Leaflet otherwise focuses the map container on click → host scrolls the iframe into
  view); a MutationObserver strips `tabindex`/`role` from marker + cluster icons (markercluster re-adds them); and
  the detail sheet only takes focus for keyboard-initiated opens (`openSheet(v, m, focusClose)`, where list cards pass
  `e.detail === 0`). Focusing anything inside a cross-origin iframe scrolls the host — so pointer taps focus nothing.
- **Brand:** Matter font; blue-first palette in `:root`
  (`--blue #2659FF`, `--mid-blue #0D2880`, `--dark-blue #07184D`,
  `--cool-grey #EDF4FF`). Red `#CA0016` is reserved for breaking news — **do not
  use it**. Corners are intentionally subtle (small radii).

## Run locally

```bash
python3 -m http.server 8000      # then open http://localhost:8000/
```

Rebuild data only when the xlsx changes (deps: `pip install -r build/requirements.txt`):

```bash
python build/build_data.py            # reuse downloaded teasers
python build/build_data.py --refresh  # re-fetch all og:images
python build/build_geo.py             # rarely needed (boundaries)
```

Testing is done with Playwright against a local `http.server` (the
`webapp-testing` skill). Check console errors and screenshot desktop + mobile
viewports after UI changes.

## Deploy / update

It's a normal git repo with `origin` set. To publish changes:

```bash
git add -A && git commit -m "…" && git push
```

GitHub Pages rebuilds automatically (~1 min). Do **not** commit `cd_ci/`
(git-ignored: internal brand assets + commercial Matter source fonts). The
`.woff2` web fonts in `assets/fonts/` are served publicly by design.
